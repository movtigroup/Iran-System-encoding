# کتابخانه انکودینگ ایران سیستم برای پایتون

این کتابخانه ابزاری حرفه‌ای و با کارایی بالا برای تبدیل متن‌های یونیکد به کدگذاری قدیمی **ایران سیستم (Iran System)** و بالعکس است.

## ✨ ویژگی‌های کلیدی

- **🚀 هسته دوگانه**: بهره‌گیری از افزونه C برای سرعت حداکثری و جایگزین خالص پایتونی (Pure Python) در صورت نیاز.
- **📦 بدون وابستگی**: تمام منطق‌های لازم (از جمله Reshaping و Bidi) در داخل کتابخانه پیاده‌سازی شده و نیازی به نصب بسته‌های اضافی نیست.
- **🧠 مدیریت هوشمند متن**: شناسایی خودکار کلمات انگلیسی و اعداد در میان متن فارسی و حفظ ترتیب بصری صحیح آن‌ها.
- **🔢 معکوس‌سازی اعداد**: پشتیبانی از قوانین خاص پایانه‌های قدیمی برای معکوس کردن اعداد فارسی (مثلاً نمایش "۱۰" به صورت "۰۱" در بافر بصری).
- **🛡️ پشتیبانی کامل**: پوشش تمامی حروف فارسی، ترکیبات خاص (مثل لا) و حالت‌های مختلف حروف.

## 🚀 شروع سریع

```python
from iran_encoding import encode, decode

# تبدیل یونیکد به ایران سیستم
text = "سلام 123"
encoded = encode(text)
print(encoded.hex())  # خروجی: 81828320f491f3a8

# تبدیل ایران سیستم به یونیکد
decoded = decode(encoded)
print(decoded)  # خروجی: سلام ۱۲۳
```

## 📖 جزئیات فنی

### ترتیب بصری هوشمند (Smart Global RTL)
این کتابخانه از استراتژی معکوس‌سازی سراسری هوشمند استفاده می‌کند. یعنی کل خط را برای نمایش در ترمینال‌های بصری معکوس می‌کند، اما بخش‌های انگلیسی و اعداد انگلیسی را شناسایی کرده و ترتیب آن‌ها را به صورت چپ‌به‌راست (LTR) حفظ می‌کند.

### تفاوت اعداد فارسی و انگلیسی
- **اعداد انگلیسی** (`0-9`): به صورت چپ‌به‌راست باقی می‌مانند (مثلاً "123" همان "123" می‌ماند).
- **اعداد فارسی** (`۰-۹`): طبق درخواست سیستم‌های قدیمی، به صورت بصری معکوس می‌شوند (مثلاً "۱۰" تبدیل به "۰۱" می‌شود).
